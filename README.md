# Corner Shop Restock

A restock app a corner shop will actually use — built for the **InfiniSynapse Vibe Coding Hackathon 2026**.

## The idea

Corner shops lose money on stock: things run out silently, or pile up and expire. This app helps a small shop track what's on the shelf, predict what will run out, and place restock orders before it hurts.
